Examples#

This gallery walks through every public feature of mathematicskit.information_theory: entropy, mutual information and divergence; lossless source codes from Shannon-Fano and Huffman to arithmetic coding and Lempel-Ziv; channel capacity, the noisy-channel coding theorem and rate-distortion; and error-correcting codes from Hamming to Gallager’s LDPC codes.

Each script in this gallery is self-contained and can be run directly with python examples/information_theory/<section>/<script>.py.

Sections#

  • entropy – Hartley’s measure, Shannon entropy, mutual information, and the Kullback-Leibler divergence.

  • source_coding – the typical set, Shannon-Fano and Huffman codes, the Kraft-McMillan inequality, Elias gamma codes, arithmetic coding, and LZ78.

  • channels – capacity of the binary symmetric and Gaussian channels, random codes, rate-distortion, and Blahut-Arimoto.

  • channel_codes – Hamming codes, convolutional codes and Viterbi decoding, and LDPC codes with bit flipping.
