    <div class="sphx-glr-thumbcontainer" tooltip="Pollard&#x27;s p - 1 method finds a prime p \mid n when the group (\mathbb Z/p)^\times, of order p - 1, has only small prime factors; if it does not, the method is stuck. Lenstra (1987) replaced that one group by the groups of points of random elliptic curves y^2 = x^3 + ax + b over \mathrm{GF}(p). By Hasse&#x27;s theorem their orders scatter over [p + 1 - 2\sqrt p,\ p + 1 + 2\sqrt p], so a bad curve is cured by trying another one, until some curve&#x27;s order happens to be smooth.">
