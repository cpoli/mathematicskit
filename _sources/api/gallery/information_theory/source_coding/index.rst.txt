Source coding
-------------

Lossless compression: from the typical set to Huffman, arithmetic, and Lempel-Ziv codes.

Almost all the probability then sits on about 2^{nH} &quot;typical&quot; sequences out of 2^n, so nH bits suffice to describe the source, and no lossless code can do better on average.">
