    <div class="sphx-glr-thumbcontainer" tooltip="Jean le Rond d&#x27;Alembert (1747) showed that every solution of u_{tt} = c^2 u_{xx} is a sum of two waves moving in opposite directions, u = F(x - ct) + G(x + ct). A plucked string&#x27;s triangular bump therefore splits into two half-height copies that run apart, reflect upside down at the fixed ends, and recombine. This script compares d&#x27;Alembert&#x27;s formula with a leapfrog finite-difference string (mathematicskit.integrators.leapfrog_integrate) run at Courant number 1, where the scheme reproduces d&#x27;Alembert&#x27;s solution exactly at the grid points.">
