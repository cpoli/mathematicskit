The travelling salesman problem
---------------------------------

Nearest-neighbour and 2-opt heuristics against the exact Held-Karp
algorithm.

    <div class="sphx-glr-thumbcontainer" tooltip="A salesman must visit n cities and return home by the shortest route. Trying all (n-1)!/2 tours is hopeless beyond a dozen cities; Held and Karp (1962) found the optimum in O(n^2 2^n) steps by dynamic programming over the set of cities visited so far, still the best worst-case bound known. Heuristics are faster but inexact: the nearest-neighbour tour, and Croes&#x27;s 2-opt move, which reverses a segment whenever that removes a crossing.">
