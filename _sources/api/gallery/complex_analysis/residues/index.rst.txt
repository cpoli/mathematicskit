The modern topological proof counts windings: on a huge circle p(z) \approx z^n winds n times around 0, on a tiny circle about a non-root it winds 0 times, so as the circle grows the image curve must pass through 0 -- and the argument principle says it does so exactly n times.">

Picture f(\gamma) as a person walking around a lamppost at 0 and g as the leash to a dog at f + g: a leash shorter than the distance to the post means the dog circles it the same number of times. Here z^5 + 3z + 1 has all five zeros in |z| &lt; 2 (dominated by z^5) and exactly one in |z| &lt; 1 (dominated by 3z).">
