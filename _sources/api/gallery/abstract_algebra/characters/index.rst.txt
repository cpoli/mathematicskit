    <div class="sphx-glr-thumbcontainer" tooltip="In 1896 Frobenius attached to each finite group a square table of numbers: one row per irreducible character \chi(g) = \operatorname{tr}\rho(g), one column per conjugacy class. The rows are orthonormal, the squares of the first column sum to |G|, and the table encodes much of the group&#x27;s structure in a handful of numbers. Here the tables are computed by Burnside&#x27;s algorithm, from the class multiplication constants alone, without constructing any representation.">
