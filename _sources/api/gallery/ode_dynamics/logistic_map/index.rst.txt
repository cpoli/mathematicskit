The logistic map
----------------

The period-doubling route to chaos and the Feigenbaum constant, and an
animated cobweb diagram as :math:`r` grows.

    <div class="sphx-glr-thumbcontainer" tooltip="As the parameter r grows, the logistic map x \mapsto rx(1-x) doubles its period again and again -- 1, 2, 4, 8, ... -- at parameter values whose spacing shrinks by a constant factor, Feigenbaum&#x27;s \delta \approx 4.6692. Universality means the same \delta appears for any smooth one-humped map. This script measures \delta for the logistic map and for the unrelated sine map x \mapsto r\sin(\pi x) and shows both sequences of ratios converging to the one constant.">
