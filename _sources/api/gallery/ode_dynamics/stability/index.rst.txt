Fixed-point stability
----------------------

Jacobian linearization and the trace-determinant classification of
node/saddle/spiral/center fixed points.

    <div class="sphx-glr-thumbcontainer" tooltip="Poincaré&#x27;s qualitative theory sorts a planar fixed point into one of four types -- node, saddle, spiral (focus), or center -- using only the eigenvalues of the linearized flow, without solving the equations. The eigenvalues depend only on the Jacobian&#x27;s trace \tau and determinant \Delta, so every type occupies its own region of the (\tau, \Delta) plane. This script classifies six canonical matrices, draws their phase portraits, and places each one on Poincaré&#x27;s trace-determinant diagram.">
