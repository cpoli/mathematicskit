Function approximation
----------------------

Approximating a function over a whole interval: Bernstein polynomials and
the Weierstrass theorem, Padé rational approximants, and Remez's best
uniform (minimax) polynomials.

Sergei Bernstein&#x27;s 1912 proof builds the polynomials explicitly: average f(k/n) with binomial weights. This script approximates a function with a kink, |x - 1/2|, and shows the uniform error shrinking, slowly, as the degree grows.">
