It also fixed the rounding rule (round to nearest, ties to even) and the special values (signed zeros, subnormals, infinities, NaN). Machine epsilon, the gap between 1 and the next float, is 2^{-52} in double precision. Floats are equally spaced within each binade [2^e, 2^{e+1}), and the spacing doubles from one binade to the next, so their relative spacing stays roughly constant.">

The subtraction itself is exact, but it exposes the rounding error that \sqrt{b^2 - 4ac} already carries. By the loss-of-precision theorem, about -\log_2|1 - y/x| of the 53 significant bits are lost when computing x - y. The cure is to compute only the root that involves no cancellation and get the other from x_1 x_2 = c/a.">
