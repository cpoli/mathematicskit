Examples
========

This gallery walks through every public feature of ``mathematicskit.calculus``:
finite-difference differentiation and Richardson extrapolation,
quadrature rules, forward- and reverse-mode automatic differentiation,
and Taylor series.

Each script in this gallery is self-contained and can be run directly with
``python examples/calculus/<section>/<script>.py``.

Sections
--------

- **exhaustion** -- Archimedes' polygon bounds on pi.
- **newton_leibniz** -- the derivative and the integral as limits of
  difference quotients and sums.
- **finite_differences** -- Richardson extrapolation, Fermat's
  adequality, and the complex-step derivative.
- **quadrature** -- Riemann sums, Simpson's rule, Gauss-Legendre,
  Euler-Maclaurin, Romberg, Clenshaw-Curtis, tanh-sinh, and adaptive
  (QUADPACK) quadrature.
- **dual_numbers** -- forward-mode automatic differentiation with no
  finite-difference truncation error.
- **autodiff** -- reverse-mode (backpropagation-style) automatic
  differentiation for multivariable gradients.
- **taylor_series** -- Taylor's theorem: Taylor polynomials, the
  Lagrange remainder bound, and radius of convergence.
