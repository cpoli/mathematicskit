mathematicskit.combinatorics
============================


.. include:: /_generated/nav/combinatorics.rst

Permutation/combination counting via ``scipy.special.perm``/``comb``
(sequence generation via ``itertools``); binomial/multinomial
coefficients, with a hand-rolled Pascal's-triangle build kept as a
pedagogical illustration; integer partitions and Young/Ferrers diagrams;
the inclusion-exclusion principle and derangements; Stirling numbers,
Catalan numbers, and Bell numbers.
