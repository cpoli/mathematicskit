mathematicskit.integrators
==========================

Shared ODE integrators used by ``ode_dynamics`` and ``pde``: fixed-step RK4,
symplectic leapfrog and Yoshida, adaptive Dormand-Prince, hand-rolled
backward Euler and scipy's Radau/BDF for stiff systems, and collocation
for two-point boundary-value problems. The "Numerical integration" and
"Stiffness and boundary-value problems" sections of the
:doc:`ode_dynamics gallery </api/gallery/ode_dynamics/index>` demonstrate
each one, and :doc:`/history/ode_dynamics_breakthroughs` covers their
history.
